This Discord bot lets server administrators configure a channel, search phrases, and an interval for posting profile pictures. On each scheduled attempt, it selects one configured phrase and uses Pinterest’s partner search API to identify matching Pin IDs. It posts an image to Discord only if the Pin ID matches a copy the operator has already reviewed and has permission to redistribute. The bot uses Pinterest for read-only search and does not create, edit, or save Pins.
